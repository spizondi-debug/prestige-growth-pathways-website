# Real photography only

This folder holds the site's photography. **Use real, licensed photographs
only.** Do **not** add AI-generated images of people, offices, factories,
classrooms, agriculture or teams.

## How to add a photo
1. Choose a real, licensed photo — good sources: **Pexels**, **Unsplash**,
   **Pixabay** (or genuine Prestige Tutelage photography).
2. Optimise it: ~1600px wide, WebP if possible, aim for < ~250KB.
3. Save it here using the exact filename referenced in `src/data/images.js`
   (set the `src` value in that file to `<filename>` for the slot).
4. Record the source and photographer in `/IMAGE-CREDITS.md`.

## Image direction
South African workplaces and training: facilitators and learners,
manufacturing and production teams, agriculture and agri-processing, logistics,
retail, professional services and public sector, workplace mentoring and
management development. Natural, documentary-style, authentic — no staged
handshakes, no futuristic overlays, and **no director/leadership portraits**.

Until a real file is added for a slot, the site renders a clean branded panel
instead — it never shows a placeholder or AI photo.
