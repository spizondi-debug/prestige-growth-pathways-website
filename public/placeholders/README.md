# Image placeholders

This folder is reserved for real imagery (photography, brand renders, resource
cover art, leadership headshots, partner logos).

The current site intentionally uses **bespoke SVG + gradient art** instead of
stock photos to keep the futuristic, premium feel. When you're ready to add real
images:

1. Drop optimised assets here (prefer `.webp` / `.svg`).
2. Reference them from the relevant component or data file in `src/data/`.
3. Keep the brand gradient / glass treatment around photos for consistency.

Recommended sizes:
- Resource cover art: 1200 × 900
- Leadership headshots: 400 × 400 (square, centred)
- Open Graph share image: 1200 × 630
